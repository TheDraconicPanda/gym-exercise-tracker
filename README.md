# Gym Exercise Tracker

A small, mobile-friendly workout tracker for a beginner four-day gym routine. Built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern browser. No build step, framework, server, or account is required.

## Current version

**v0.1.0 — Phase 1: Foundation**

- Responsive weekly schedule for Monday, Wednesday, Thursday, and Saturday.
- Displays the planned exercises, set/rep targets, warm-ups, and estimated session length.
- Highlights the current scheduled day using the device's local date.
- Includes conservative training reminders.

## Planned phases

1. **Foundation:** layout and schedule (current).
2. **Workout logging:** record each set's weight, reps, and completion.
3. **Local persistence:** retain workout sessions in this browser using local storage.
4. **Progress:** review strength history and workout consistency.

## Storage and privacy

Workout logging and history are not implemented yet. The planned tracker stores data locally in the browser and does not require an account or cloud service.

## Training plan note

Use comfortable ranges and controlled movements. Start light, leave roughly three reps in reserve, and rest 60–90 seconds between sets. Stop or adjust movements that cause pain; seek an appropriate clinical assessment if knee symptoms recur, worsen, or affect normal walking.
